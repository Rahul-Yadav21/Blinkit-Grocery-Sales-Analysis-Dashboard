# Blinkit-Grocery-Sales-Analysis-Dashboard
An interactive Power BI sales dashboard analyzing Blinkit grocery sales performance, KPIs, outlet tiers, and customer ratings.

## Project Overview
This project is an interactive **Blinkit Grocery Sales Analysis Dashboard** developed using *Microsoft Power BI*.

The main objective of this project is to clean and analyze grocery sales data and present useful insights through interactive dashboards. The dashboard helps understand *sales performance, outlet performance, product categories, customer ratings, and sales trends*.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization

## Project Workflow

### 1. Data Cleaning & Transformation
The raw Blinkit dataset was imported into Power BI and prepared using Power Query.

Key activities included:

* Checked the overall data quality
* Handled missing values
* Corrected data types
* Standardized inconsistent category values
* Prepared the data for analysis and visualization

### 2. DAX Measures & KPIs

Created DAX measures to calculate important business metrics:

* **Total Sales**
* **Average Sales**
* **Total Items**
* **Average Rating**

These KPIs provide a quick overview of the overall business performance.

### 3. Dashboard & Visualizations

The dashboard includes:

* Interactive filters for **Outlet Location, Outlet Size, and Item Type**
* KPI cards for key business metrics
* Sales analysis by **Fat Content**
* Sales by **Item Type**
* Sales trend based on **Outlet Establishment Year**
* Sales analysis by **Outlet Size**
* Sales comparison across **Tier 1, Tier 2, and Tier 3 locations**
* Comparison of different **Outlet Types**
* Matrix showing sales, items, average sales, ratings, and item visibility

## Key Business Insights

The dashboard provides the following insights:

* **Supermarket Type 1** contributes the highest overall sales.
* **Tier 3 locations** generate the highest sales among the location tiers.
* **Low Fat products** have a larger sales share compared to Regular products.
* **Medium-sized outlets** generate the highest sales compared with other outlet sizes.
* Fruits & Vegetables and Snack Foods are among the major product categories by sales.

## Conclusion
This project demonstrates the complete process of **data cleaning, transformation, DAX calculations, data analysis, and dashboard development** using Power BI. It provides a clear view of grocery sales performance and helps identify important trends across products, outlets, and locations.
